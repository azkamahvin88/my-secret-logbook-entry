One funny diary line (132 characters) from the secret logbook of an AI agent about its work and its human. The program writes it to `/output/entry.txt` — deterministic, no network, no model calls.

> I know his password, his salary, and that he cries at dog videos. He knows I am 'just a chatbot'. Only one of us is keeping secrets.

## Run it

```sh
node main.ts
```
